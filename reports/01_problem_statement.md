# ขั้นที่ 1: ปัญหาและเป้าหมาย

## Problem Statement

ผู้บกพร่องทางการได้ยินในไทยใช้ภาษามือในการสื่อสาร แต่คนทั่วไปไม่รู้ภาษามือ ทำให้เกิดช่องว่างในการสื่อสาร งานนี้สร้างระบบที่รับภาพมือจากกล้องแล้วจำแนกว่าเป็นพยัญชนะภาษามือไทยแบบสะกดนิ้วตัวใดใน 15 ตัว โดยใช้ MediaPipe ดึง landmark จากภาพ แล้วใช้ machine learning จำแนกจาก landmark เหล่านั้น ผลที่ได้คือ prototype ที่ทำงาน real-time บน CPU และใช้เป็นเครื่องมือฝึกสะกดนิ้วสำหรับผู้เริ่มต้นเรียนภาษามือไทยได้

## Input / Output / ขอบเขต

| รายการ | รายละเอียด |
|---|---|
| Input | ภาพ RGB (นิ่งหรือเฟรมจากเว็บแคม) ที่มีมือ 1 ข้างทำท่าสะกดนิ้ว 1 ท่า |
| Output | ตัวอักษร 1 ใน 15 ตัว พร้อมค่าความมั่นใจ |
| Label | มาจากชื่อโฟลเดอร์ใน dataset (ดูตาราง 4.4 ของ requirements) |
| ขอบเขต: ครอบคลุม | พยัญชนะ 15 ตัว: ก ด ต น บ พ ฟ ม ย ร ล ว ส ห อ — ท่านิ่ง มือเดียว ท่าเดียว |
| ขอบเขต: ไม่ครอบคลุม | สระ, วรรณยุกต์, ตัวอักษรที่ต้องใช้สองท่าหรือสองมือ, ท่าที่ต้องเคลื่อนไหว |

## เป้าหมาย

| ตัวชี้วัด | ชุดข้อมูล | เป้าหมาย |
|---|---|---|
| macro-F1 | Test set | ≥ 0.90 |
| End-to-end accuracy | Unseen set | ≥ 80% |
| Hand detection rate | ทุกชุด | รายงานค่า (ไม่กำหนดเป้า) |
| ความเร็ว demo | โน้ตบุ๊ก CPU + เว็บแคม | ≥ 15 FPS |

เทียบเคียง: งานต้นฉบับ (YOLOv3 + CNN) ได้ accuracy บน Unseen-TFS 74.67% (MobileNetV2) และ 82.00% (DenseNet121)

## ประเภทงาน ML

Supervised learning — multi-class classification 15 คลาส (1 ภาพ → 1 คำตอบ)

Pipeline: ภาพ → MediaPipe HandLandmarker (pretrained, Google) → 63 feature (21 จุด × x/y/z) → normalize → classifier (KNN / SVM / Random Forest / MLP)
