## โครงสร้างโฟลเดอร์จริง (ต่างจาก requirements)

| Split | โครงสร้าง |
|---|---|
| Training set | `<split>/<class>/Images (JPEG)/*.jpg` |
| Test set | `<split>/<class>/Images (JPEG)/*.jpg` |
| Unseen set | `<split>/<class>/*.jpg` (ไม่มี subfolder) |
